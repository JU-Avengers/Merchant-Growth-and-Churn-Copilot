# 💳 upay Merchant Growth & Churn Copilot

An end-to-end predictive analytics and Generative AI platform designed to mitigate merchant churn and automate field agent operations for Digital Financial Services (DFS).

---

## 📌 Features & Key Capabilities

1. **Predictive Churn Scoring (XGBoost):** Evaluates merchant transactional velocity, digital payment ratio, and inactivity recency to compute real-time churn probability.
2. **AI Advisory Copilot (Google Gemini):** Synthesizes machine learning outputs into actionable field strategy reports for operations agents.
3. **Interactive Operational Dashboard (Streamlit):** Enables field managers to search merchants, inspect growth trajectories, and view field action directives.

---

## 🛠️ Tech Stack

* **Frontend Dashboard:** Streamlit
* **Data Processing & ML:** Python, Pandas, Scikit-learn, XGBoost
* **AI Copilot Synthesis:** Google Gemini API
* **Deployment & Tunneling:** Cloudflare Tunnel (`cloudflared`)
